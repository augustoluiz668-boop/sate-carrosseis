# Músicas

Arquivos MP3 instrumentais para os Reels.

## Regras obrigatórias
- Apenas instrumentais — sem letra, sem voz
- Royalty-free ou Creative Commons
- Fontes: Pixabay Music, Free Music Archive, YouTube Audio Library

## Arquivos
- `celebration.mp3` — festas, datas comemorativas (animado)
- `informativo.mp3` — curiosidades, lançamentos (tranquilo)

## Como adicionar
Coloque o arquivo .mp3 nesta pasta. O campo `music_theme` em meta.json
deve corresponder ao nome do arquivo sem extensão.
